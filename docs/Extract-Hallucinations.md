# Extract-menu hallucinations

During Schizophrenia, opening the native extract list makes one 33% roll.
A successful effect has a 90-second cooldown; the chosen wording remains stable
until the list closes. Only destination-label text is replaced. Real extracts,
requirements, timers, availability and transit behavior remain native.

Variants include the supplied fictional destinations, repeated unsettling text,
cursed combining marks, slash patterns and symbols supported by the native font.
No Webdings font is installed or downloaded; unsupported symbols become question marks.

With optional DG Testing Tools and RR advanced controls enabled, F2 offers
“Extract menu illusion - next variant”. Open the ordinary extract list once in
that raid first so the native panel reference is available. Each press cycles a
variant and opens the list; close F2 to inspect it. This bypasses chance/cooldown
for diagnostics only. Native panel destruction/disable and effect exit restore text.
